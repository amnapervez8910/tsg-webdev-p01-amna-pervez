# Amna Pervez — Personal Portfolio

A responsive single-page personal portfolio website for **Amna Pervez**, a BS Computer Science student and developer. The website presents her skills, projects, education, contact details, and downloadable CV in a professional layout.

## Live Website

[Visit the live portfolio](https://amnapervez8910.github.io/tsg-webdev-p01-amna-pervez/)

## GitHub Repository

[View the source code](https://github.com/amnapervez8910/tsg-webdev-p01-amna-pervez)

## Features

- Responsive navigation with smooth scrolling
- Hero section with introduction and call-to-action buttons
- About section with a professional bio
- Downloadable CV button
- Skills section with icons and rating indicators
- Featured projects grid with images and descriptions
- Project report buttons with repository links
- Contact form with JavaScript validation
- Gmail compose action after valid form submission
- Mobile navigation menu
- Scroll-to-top button
- CSS hover effects and animated reveal effects
- Responsive design for mobile, tablet, and desktop screens
- Footer with copyright and social links

## Run Locally

1. Clone or download this repository.
2. Keep `index.html`, `styles.css`, `script.js`, and `resume.pdf` in the same folder.
3. Open the folder in VS Code.
4. Open `index.html` with the Live Server extension.
5. You can also open `index.html` directly in a web browser.
6. Click the **Download CV** button to download the resume.
